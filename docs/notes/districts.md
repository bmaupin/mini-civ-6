# Districts

## Problems

- Districts allow cities to specialise, but this doesn't work well when playing with extremely small map sizes where each player may have 3 cities or less
- Districts clutter the map
- Placing districts on the map isn't a very interesting choice
- Have to build districts and wait for them to be built

## Solutions

#### Allow districts to be built in city centre

Reduces map clutter and eliminates decision on where to place district without removing the benefit districts provide for playing shorter games (they reduce the number of buildings available to be built in a city)

This doesn't seem possible :/

#### Remove districts

Remove districts and allow buildings to be built directly in the city centre.

My first concern was this would increase the number of items in the city build queue since buildings would no longer need districts, but instead of showing the district (e.g. campus) it would just show the next building available to be built (e.g. library). So the overall number of items available to the city should not increase.

In addition, it's one less thing to wait to build and one less decision to make.
